# 🕵️ Governança dos Dados
A fase de Governança dos Dados é essencial para garantir a qualidade, integridade e segurança das informações manipuladas no projeto de BI. Nesse contexto, estabelecer políticas, normas e processos 
claros para a gestão dos dados é fundamental. A governança visa assegurar a confiabilidade das fontes de dados, promover a conformidade com regulamentações e padrões, além de definir papéis e 
responsabilidades na administração dos ativos de informação. Ao adotar práticas robustas de governança, a organização potencializa a tomada de decisões baseada em dados confiáveis e mitigação de riscos, 
contribuindo para o sucesso contínuo do projeto de BI.


---
## ☁️ Publicação
Organização do processo de publicação no Power BI Service da TechFlow Store, estruturando o ambiente e garantindo controle de acesso adequado para fins de governança.
- Publicação do projeto no ambiente de Service;
- Estruturação de Workspace dedicado ao projeto;
- Configuração do ambiente como espaço de desenvolvimento;
- Definição e aplicação de regras de acesso;
- Concessão de permissão exclusiva ao Diretor e à Assistente.

---
## 🔑 Compartilhamento
Definição da estratégia de compartilhamento no Power BI Service da TechFlow Store, garantindo controle, segurança e clareza na distribuição das informações para stakeholders.
- Avaliação de compartilhamento direcionado por usuário (acesso específico);
- Análise de distribuição via aplicativo corporativo (App do Power BI);
- Validação das regras de visibilidade e permissão.


---
## 🔄 Gateway
Configuração do Gateway para garantir atualização automática e segura dos dados local, assegurando disponibilidade, controle e rastreabilidade do ambiente analítico.
- Configuração do Gateway;
- Definição e ativação do agendamento de atualizações automáticas;
- Planejamento de entrega e treinamento de uso para responsáveis.
